# معجم واجهة Onboard العربية

هذا المعجم إلزامي للرسائل الجديدة في `po/ar.po`. تُترك أسماء البروتوكولات
والأوامر والتقنيات، مثل `Wayland` و`X11` و`D-Bus` و`KDE` و`GNOME`، كما هي ما
لم يكن لها تعريب راسخ؛ وتُعرّب العبارة المحيطة بها بصورة طبيعية.

| English source term | الترجمة العربية المعتمدة | ملاحظة تحريرية |
|---|---|---|
| On-screen keyboard | لوحة مفاتيح الشاشة | اسم المنتج `Onboard` لا يترجم. |
| Keyboard layout | تخطيط لوحة المفاتيح | لا تستخدم «تنسيق» لهذا المعنى. |
| Input source | مصدر الإدخال | يستخدم في GNOME وKDE وX11. |
| Switch input source | تبديل مصدر الإدخال | فعل الأمر في القائمة. |
| Clipboard | الحافظة | لا تستخدم «لوح القص». |
| Clipboard history | محفوظات الحافظة | تستخدم لجمع العناصر السابقة. |
| Emoji | رموز تعبيرية | يمكن إبقاء «إيموجي» في تسمية قصيرة عند ضيق المساحة. |
| Preferences | التفضيلات | تستخدم لنافذة الإعدادات العامة. |
| Settings | الإعدادات | تستخدم للخيارات التقنية أو القسم. |
| Show | إظهار | تستخدم للوحة أو النافذة المخفية. |
| Hide | إخفاء | تستخدم للوحة أو النافذة الظاهرة. |
| Toggle | إظهار أو إخفاء | تستخدم لإجراء له حالتان. |
| Status indicator | مؤشر الحالة | لا تترجم إلى «أيقونة» إلا عند الحديث عن الرسم نفسه. |
| Quick access | استدعاء سريع | تستخدم للأمر أو زر اللوحة الدائم. |
| Word suggestions | اقتراحات الكلمات | تستخدم في شريط التنبؤ. |
| Accessibility | إمكانية الوصول | المصطلح القياسي في واجهات GNOME. |
| Right-to-left | من اليمين إلى اليسار | يشار إليه اختصاراً RTL في الوثائق التقنية. |
| Wayland compositor | مُركِّب Wayland | يحافظ على الاسم التقني. |
| Virtual keyboard | لوحة مفاتيح افتراضية | تختلف عن نافذة لوحة المفاتيح المعروضة. |
| Permission denied | رُفض الإذن | تذكر سبب التفويض عند توفره. |
| Unavailable | غير متاح | لا تستخدم «غير موجود» لميزة معطلة مؤقتاً. |

تُراجع اختصارات القوائم (`_`) بصرياً في جلسة RTL. لا تنقل الشرطة السفلية
آلياً إلى بداية العبارة العربية؛ توضع قبل حرف عربي غير مكرر في النافذة نفسها،
مع الحفاظ على عدد العلامات الذي يفرضه المصدر.
